# AGENTS

Перед коммитом добавь пункт в `CHANGELOG.md` под датой сверху (первый коммит ветки — внизу). Коммит и пуш только по прямой команде; перед коммитом покажи `git diff --cached --stat`.

Не коммитить без проверки пользователем и прямого указания: даже если попросили «закоммить», сначала показать `git status` и `git diff --cached --stat`, дождаться явного подтверждения показываемого набора файлов.
