# AGENTS

Сайт работает на Eleventy.

Правила создания, переезда и удаления страниц — в `README.md`.

«Гист» здесь — фрагмент сайта, страница в `content/gists/` с `eleventyNavigation.parent: "Фрагменты"`, а не GitHub Gist. «Выложить гист» = создать такую страницу (`permalink: gists/<slug>/`, `date`, `lastmod`, `title`), добавить пункт в `CHANGELOG.md` и проверить `npm run build`. GitHub Gist создаём только по явной просьбе про github.com/gist.github.com.

Перед коммитом добавь пункт в `CHANGELOG.md` под датой сверху (первый коммит ветки — внизу). Коммит и пуш только по прямой команде; перед коммитом покажи `git diff --cached --stat`.

Без прямой команды коммитить и пушить запрещено: закончить работу и отдать пользователю на ревью. Прямая команда «коммити/пушь» означает: сделать сразу, без переспросов — пользователь уже проверил. `git status` и `git diff --cached --stat` показываются для протокола, подтверждения после этого ждать не надо. В коммит брать только то, что менял ты; чужие правки (в том числе параллельных агентов) не коммитить и не пушить. Если файл правили вместе с пользователем — можно.
