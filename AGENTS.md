# AGENTS

Перед коммитом добавь пункт в `CHANGELOG.md` под датой сверху (первый коммит ветки — внизу). Коммит и пуш только по прямой команде; перед коммитом покажи `git diff --cached --stat`.

Прямая команда «коммити/пушь» означает: сделать сразу, без переспросов. Показать `git status` и `git diff --cached --stat` — для протокола, подтверждения после этого ждать не надо. В коммит брать только то, что менял ты; чужие правки (в том числе параллельных агентов) не коммитить и не пушить. Если файл правили вместе с пользователем — можно.
