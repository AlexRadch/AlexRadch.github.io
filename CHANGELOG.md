# CHANGELOG

История изменений сайта. Записи по датам, новые сверху.
Версии назначаются вручную по команде: третью цифру — на обычные
изменения, когда накопились; вторую — на вехи; первую — на крупные
переходы (новая версия Hugo, смена темы и т.п.). Факт назначения
фиксируется строкой в записи за дату: «Версия 0.1.0».

## 2026-09-24

- Бренд вверху левого меню (логотип + ссылка на главную) убран:
  ссылка на главную уже есть в топбаре, дублирование съедало место.
  В теме выключателя нет — добавлен свой параметр `BookBrand`
  (default true, как у темы; у нас выключен в hugo.toml; точечно
  возвращается `bookBrand: true` — пригодится на страницах без топбара).
- Параметры из main-ветки темы (у нас v0.15.0, их там нет):
  `BookBreadcrumbs` (default false, у нас включён в hugo.toml —
  вид не поменялся, точечно гасится `bookBreadcrumbs: false`)
  и `BookPageLinks` (default false — входящие/исходящие ссылки под
  оглавлением; код toc.html и render-link один в один из main-ветки,
  иконки incoming/outgoing и CSS .book-toc-section оттуда же).
  Проверено пробой на двух связанных страницах, проба снесена.
- Layout `gist` удалён: та же «страница без левого меню» получается
  глубиной `bookSectionDepth: 0` в обычном шаблоне. Три фрагмента
  переведены с `layout: gist` на глубину 0, хвосты `book-layout-gist`
  в CSS подчищены. Остались два layout: `landing` (главная) и дефолт.
- Правое оглавление закрывается само: клик по ссылке-якорю снимает
  `toc-control` (`toc-autoclose.js`) — как левое меню, которое
  закрывается за счёт перезагрузки страницы. Руками закрывать не надо.
- Якоря не уезжают под прилипшую строку: `scroll-margin-top` у
  заголовков с запасом на высоту строки. Текст не сдвигается, запас
  только в момент прокрутки к якорю. Не понравится — удалить правило.
- Узкий хедер прилипает: строка с кнопками меню/оглавления
  (`position: sticky`, чистый CSS) остаётся вверху при прокрутке —
  меню доступно из любого места страницы. В потоке остаётся, текст
  ниже не перекрывается. Раскрытое правое оглавление прилипает под
  строкой, иначе перекрывало бы кнопки и его нельзя было закрыть.
- Левое меню по глубине: `bookSectionDepth: 0` (и ниже) — меню нет
  вообще, ни себя ни детей; гамбургер в узком хедере тоже не рисуется.
  Починен `default 999` (съедал 0): глубина через `menu-depth.html`
  с явной проверкой на nil. `menu-container` в baseof тоже gated.
- Узкий хедер: классы `no-menu-btn` / `no-toc-btn` снимают маргин `h3`
  с той стороны, где кнопки нет (дефолтный `header.html`, gist не тронут).
- Узкий хедер: в `h3` — титул корня левого меню (`menu-root-title.html`,
  то же разрешение что у меню), а не текущей страницы: фрагмент —
  «Фрагменты», глава — название книги. Как у темы (там всегда книга).
- Правое оглавление прячется само: если в ToC 0–1 пункт (нет
  подзаголовков, только H1 вверху), `book-toc` и кнопка `toc-control`
  не рисуются — ни десктоп, ни мобильный хедер. Отдельного темплейта
  нет: тот же шаблон считает пункты (`findRE "<li" .TableOfContents`).
  `bookToC: false` по-прежнему главнее.
