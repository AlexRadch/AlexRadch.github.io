# CHANGELOG

История изменений сайта. Записи по датам, новые сверху.
Версии хлопаем вручную, когда есть что зафиксировать: третью цифру —
на обычные изменения, вторую — на вехи, первую — на крупные переходы
(новая версия Hugo, смена темы и т.п.).

## 2026-09-22

- Статья Pirate Face: ссылки на Hugging Face, лицензии Apache-2.0/MIT,
  Meta, BitTorrent, AI-модели, SHA-256 (русская Википедия), новость
  о закрытии Papers with Code, пост на Hacker News.
- Картинка статьи: og:image с pirateface.co хотлинком (не скачиваем),
  вставлена в текст через шорткод figure справа с обтеканием
  (класс `.figure-right`, клик ведёт на сайт).
- `article:section` — русский титул раздела («Фрагменты») вместо
  технического имени каталога (свой `layouts/_partials/opengraph.html`,
  исходник Hugo скопирован один в один, изменён только блок секции).
- Русское «гист» заменено на «фрагмент» везде (английские имена
  `layout: gist`, каталог `gists/`, шорткод — не тронуты).
- Топбар: плавные отступы без скачков на границе 90rem (clamp вместо
  медиа-запроса), скорости ползущих отступов синхронизированы.
- Боковые панели и `main`: теминые скачки gap/padding на 90rem
  переопределены плавными формулами.
- Отладочные флажки: `BookMenuDebug` → `DebugBookMenu` (+`DEBUG-MENU`),
  новый `DebugTopbarCss` (подсветка границ топбара и контента,
  глушится параметром).
- Тестовые разделы `tests/` и `gists/test-book/` — черновики через
  `cascade.draft` (из сборки исчезают, в меню их нет).
- Мобильный хедер фрагмента: гамбургер убран, заголовок прижат влево
  (распорка `gist-spacer` удалена, левый отступ `h3` убран только
  для `book-layout-gist`).
- Поиск починен: бэкенд сменён с firecrawl (403 на Free plan) на рабочий.
